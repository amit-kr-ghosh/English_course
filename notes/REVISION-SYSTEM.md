# Spaced Revision System

For every meaningful topic, schedule:
- D+1: recall core rules and reattempt errors.
- D+7: solve a fresh short question set.
- D+15: mixed questions without notes.
- D+30: mini-test and update confidence.

If accuracy is below 70%, revisit the concept and schedule another short practice set within 2–3 days. If accuracy is 70–85%, continue the spaced cycle. If above 85% twice on fresh questions, move to maintenance revision.

Always reattempt logged mistakes. Do not count reading notes as a completed revision; use active recall and questions.
