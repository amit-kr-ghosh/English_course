# Daily Study Notes

This directory stores one Markdown file per calendar date with actual study activity.

## Naming
- `YYYY-MM-DD.md` — for example, `2026-11-12.md`
- Use the date in India Standard Time (Asia/Kolkata).
- If more than one study conversation happens on the same date, append to the existing file.

## What to record
Copy the structure from [the daily log template](../templates/DAILY-LOG.md). Capture the topics and concepts studied, PYQ source and results, mistakes and their explanations, vocabulary, revisions, descriptive-writing feedback, and next-session target.

## Accuracy and integrity
- Only create/update a dated study note when study activity is actually reported or verified.
- Never fabricate study time, attempts, scores, concepts, or completed revisions.
- Leave unknown fields blank.
- Keep detailed explanations here; update the CSV trackers for structured data and the dashboard for a concise progress snapshot.
- Do not create duplicate notes for the same date.

The master rules live in the repository [README.md](../README.md).
