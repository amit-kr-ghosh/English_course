# Daily Study Notes

This directory stores one Markdown file for each actual study day, numbered sequentially.

## Naming and numbering
- `Day-01.md`, `Day-02.md`, `Day-03.md`, and so on.
- **The number represents the sequence of completed study days, not the calendar date.**
- Record the calendar date inside each note as metadata, in Asia/Kolkata.
- A missed day does not increment the number. The next completed study day uses the next number.
- If multiple chats or study sessions belong to the same study day, append to that day's file.
- Before creating a file, inspect the existing notes and continue from the highest valid Day number. Never overwrite or duplicate a day.

## What to record
Copy the structure from [the daily log template](../templates/DAILY-LOG.md). Capture topics and concepts studied, PYQ source and results, mistakes and explanations, vocabulary, revisions, descriptive-writing feedback, and the next-session target.

## Accuracy and integrity
- Only create/update a numbered note when study activity is actually reported or verified.
- Never fabricate study time, attempts, scores, concepts, or completed revisions.
- Leave unknown fields blank.
- Keep detailed explanations here; update CSV trackers for structured data and the dashboard for a concise progress snapshot.
- Do not create a note for a missed day or an unreported session.

The master rules live in the repository [README.md](../README.md).
